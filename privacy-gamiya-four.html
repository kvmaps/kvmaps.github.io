WHAT PERSONAL INFORMATION DOES "Gamiya Four" COLLECT?

These applications work as offline apps. They do not send any data to a developer backend. All location data collected from the apps is only saved inside the apps. Thus, "Gamiya Four" does not collect any data from these applications. Every data collected from users (your location, your places search queries) is only saved inside the applications. All these data will be deleted when you uninstall the applications.
