WHAT PERSONAL INFORMATION DOES "KV Maps" COLLECT?

These applications work as offline apps. They do not send any data to a developer backend. All location data collected from the apps is only saved inside the apps. Thus, "KV Maps" does not collect any data from these applications. Every data collected from users (your location, your places search queries) is only saved inside the applications. All these data will be deleted when you uninstall the applications.

APPLICATION PARTNER TREATMENT OF PERSONAL INFORMATION.

"KV Maps" will not provide personal information to the applicable Application Partner.

WILL "KV Maps" SHARE ANY OF THE PERSONAL INFORMATION IT RECEIVES?

"KV Maps" will not provide any personal information it receives.
